# ⚖️ Legal Document Explainer Bot

An AI-powered tool that simplifies complex legal documents into easy-to-understand summaries.

## 🚀 Features

- Plain-English summaries
- Clause-by-clause explanation
- Legal risk highlighting
- Key obligation extraction
- Important date detection
- Adjustable explanation level
- Styled modern UI
- Downloadable output

## 🧠 How It Works

The app uses Google Gemini to:
- Analyze legal language
- Simplify terminology
- Extract obligations and risks
- Provide structured summaries

## 🛠 Tech Stack

- Python
- Streamlit
- Google Gemini API

## 🌍 Deployment

Add API key in Streamlit Cloud:

App → Settings → Secrets
